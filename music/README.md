# 项目音乐文件夹

页面会在启动后读取 `music/manifest.json`，自动显示并预加载 `music` 文件夹中的音频文件。这个清单文件需要在新增、删除或重命名音乐后同步更新。
也可以在网页的“音乐”面板中点击“选择项目音乐文件夹”，选择当前项目下的 `music` 文件夹并授予写入权限；此授权只在当前页面会话有效。
之后通过文件选择或拖拽导入的本地音频会复制到此目录，同时加入页面播放列表。若文件同名，系统会自动追加序号，避免覆盖已有音乐；若要让新文件在下次静态部署启动时自动出现，还需要把它加入 `manifest.json`。

浏览器出于安全原因不会允许网页无提示地枚举或写入本地目录。GitHub Pages 等静态托管通过 `manifest.json` 获取清单；直接打开 `index.html` 时请使用文件选择或拖拽导入。未选择此目录时，导入的音乐只在当前页面会话中可播放。文件夹读写依赖 Chromium 系浏览器的 File System Access API，但不是项目运行必需项。

浏览器通常禁止页面在没有用户操作时自动播放声音。因此启动时会预加载第一首音乐并将其设为默认曲目，进入音乐面板后点击“播放”即可开始。
